# On Off Bulb 💡🔦

## 🌟 Overview
A delightful and interactive web application that brings the classic light bulb experience to your browser! Experience the magic of toggling a virtual bulb on and off with smooth animations and vibrant visuals. Perfect for demonstrating basic web interactions or just having fun! ✨🎉

## 🚀 Live Demo
Check out the live version here: [https://iam269.github.io/On-Off-Bulb/](https://iam269.github.io/On-Off-Bulb/) 🌐

## 🎯 Features
- **Interactive Toggle**: Click the button to switch the bulb between ON and OFF states 🔄
- **Smooth Animations**: Enjoy fluid transitions and glowing effects when the bulb lights up 💫
- **Responsive Design**: Works seamlessly on desktop and mobile devices 📱💻
- **Simple & Clean UI**: Minimalist design focused on the bulb interaction 🎨
- **No Dependencies**: Pure HTML, CSS, and JavaScript - no external libraries needed 🛠️

## 📖 How to Use
1. Open the `index.html` file in your web browser 🌍
2. Click the "ON" button to light up the bulb 🔘➡️💡
3. Click again to turn it off and watch the glow fade 💡➡️🔘
4. Enjoy the satisfying toggle experience! 😊

## 🛠️ Technologies Used
- **HTML5**: Structure and semantic markup 📄
- **CSS3**: Styling, animations, and responsive design 🎨
- **JavaScript (ES6)**: Interactive functionality and DOM manipulation ⚙️
- **Google Fonts**: Custom typography with Poppins font family 🔤

## 🎨 Customization
Feel free to customize the bulb's appearance by modifying the CSS variables in `style.css`:
- Change colors for different themes 🌈
- Adjust animation timings for faster/slower transitions ⏱️
- Modify sizes for different screen layouts 📏
